Tool for AI agents

VerifyLite

Verify before you pay or act. One cheap call tells an agent whether a site, a transaction or a token is safe to touch, with the reasons.

Open the service See the listing

Pay per request, no account

VerifyLite gives AI agents pay-per-request website safety checks, web utilities, transcription, Base on-chain data and agent basics. Agents pay per call in USDC on Base through x402, so there is no sign-up and no subscription. It runs on Cloudflare Workers and is also available as an MCP server.

The site check looks at technical signals: TLS, redirects, mixed content, forms and domain age. It does not claim to detect phishing. See the measured accuracy.

Verify before you act

  • Before you visit or pay a site: check the site
  • Before your model reads text: check it for prompt injection
  • Before you buy or accept a token on Base: get a token report

What it can do

Website safety

Passive checks of TLS, redirects, security headers, mixed content, insecure forms and domain age, one site or a batch.

Web utilities

Pages as clean markdown, link previews, domain reports, email checks and SEO checks.

Agent safety

Prompt injection detection, package vulnerability checks and JSON repair for model output.

Transcription

Speech to text by URL, with timed segments and SRT and WebVTT captions.

On-chain data

Token reports and other Base on-chain data for agents that handle payments.

Endpoints and current prices are published by the service itself at its live address.
